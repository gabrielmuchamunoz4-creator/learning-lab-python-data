# learning-lab-python-data

Repositorio personal de aprendizaje creado para desarrollar fundamentos de programación, Python, Git, terminal y manejo de datos como parte de mi ruta de formación hacia Data Engineering.

## Objetivo

Construir progresivamente habilidades prácticas en Python y herramientas de desarrollo, priorizando la comprensión y la capacidad de escribir, modificar y explicar el código de forma autónoma.

Este repositorio irá almacenando ejercicios y pequeñas prácticas realizadas durante las primeras etapas de aprendizaje.

## Requisitos

Para trabajar con este repositorio se necesita:

* Python 3
* Git
* Visual Studio Code o cualquier editor de código
* pip

## Preparación del entorno

El proyecto utiliza un entorno virtual de Python para mantener sus dependencias aisladas de otros proyectos.

Después de crear y activar el entorno virtual, las dependencias necesarias pueden instalarse utilizando el archivo `requirements.txt`.

## Dependencias actuales

Actualmente el proyecto utiliza:

* `requests`

Las dependencias adicionales requeridas por esta librería también están registradas en `requirements.txt`.

## Estructura inicial

```text
learning-lab-python-data/
├── .gitignore
├── requirements.txt
└── README.md
```

La carpeta `.venv` existe localmente, pero no se incluye en Git porque cada usuario puede reconstruir su propio entorno virtual utilizando `requirements.txt`.
